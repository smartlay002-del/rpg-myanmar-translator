RPG Maker MV / MZ Map JSON ထဲက Dialogue (Show Text) နဲ့ Choice စာသားတွေကိုပဲ ဘာသာပြန်ပါမယ်။

ဘာတွေကို ပြန်မလဲ?

  • Dialogue စာသားများ (RPG Maker command 401)
  • Choice ရွေးချယ်စရာများ (command 102)

ဒီဗားရှင်းမှာ Event Script, ID, Variable, Game Command နဲ့ JSON Key တွေကို မပြောင်းပါ။ Item / Quest database ဖိုင်တွေကို သီးခြား format စစ်ပြီးမှ ထည့်သွင်းရပါမယ်။

API key ကို browser ထဲမထည့်ပါနှင့်။ Server environment variable ထဲတွင်သာ သိမ်းပါ။
